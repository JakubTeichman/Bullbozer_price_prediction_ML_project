# Bulldozer Price Prediction ML Project

## 📌 Project Description

This project builds a machine learning model to predict the prices of bulldozers based on historical auction data. The goal is to analyze key factors influencing bulldozer prices and develop a model that provides accurate price estimates.

## 📊 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📊 Dataset

The dataset is sourced from the [Kaggle Blue Book for Bulldozers](https://www.kaggle.com/c/bluebook-for-bulldozers) and contains information such as:

- Sale price
- Year of manufacture
- Machine usage hours
- Equipment type and model
- Auction location
- Sale date

## 🔍 Methods

The best model is selected based on metrics like **Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score**.

## 📈 Visualizations & Results

The project includes visual analyses of model results, including:

- Feature importance plots
- Price distribution graphs
